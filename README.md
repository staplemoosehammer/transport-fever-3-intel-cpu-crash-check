## 📁 How It Works — Troubleshooting Workflow

1. Identify the exact Intel CPU model and read the official Transport Fever 3 known-issues page.
2. Check the motherboard vendor’s support page for BIOS versions, microcode updates and stability guidance.
3. Compare current CPU power settings against the CPU/motherboard manufacturer’s recommended baseline; avoid untested manual overclock changes.
4. Test the same unmodded map and graphics settings after restoring supported defaults.
5. Check Windows Reliability Monitor and Event Viewer for crashes near the test time.
6. If instability persists, document the CPU, BIOS revision, power settings, mods and crash reproducibility for official support.

## 🛠️ Troubleshooting Notes

BIOS updates should follow the hardware vendor’s instructions; this repository does not modify firmware.

If nothing changes, describe the exact symptom, current game version, Windows build, driver version and the last successful launch or working configuration when requesting official support.
